# Venera 包子漫画补充源

为 Venera Prime 提供的独立包子漫画源。针对部分网络环境下原源访问失败、主站需要网页验证、图片服务器连接失败的问题，提供主站入口与图片线路切换。

这是社区补充版本，不代表 Venera 官方，也不意味着原源在所有环境中都不可用。

## 安装（无需懂代码）

建议使用 **Venera Prime 2.4.2 或更新版本**。

### 方法一：添加源目录（推荐）

1. 软件首页 → **漫画源** → **源目录** → 右上角 **＋**。
2. 目录名称填写 **包子漫画补充源**。
3. URL 填写下面的地址，然后确认：

```text
https://raw.githubusercontent.com/lizhenghe616/venera-baozi-source/main/index.json
```

4. 打开刚添加的目录，点击 **包子漫画（主站）** 右侧的 **＋**。

### 方法二：直接安装单个源

软件首页 → **漫画源**，在“添加漫画源”的 URL 栏粘贴：

```text
https://raw.githubusercontent.com/lizhenghe616/venera-baozi-source/main/baozi.js
```

也可下载本仓库的 [baozi.js](baozi.js)，使用软件中的“使用配置文件”导入。

源的独立标识为 `baozi_www`，可与原版 `baozi` 共存。已经安装旧补充版本的用户，请通过本目录更新或重新导入，并重新打开漫画详情后阅读。

## 首次使用与网页验证

如果搜索提示“主站要求网页验证”：

1. 进入 **漫画源 → 包子漫画（主站） → 登录**。
2. 选择 **使用网页登录**，在软件内完成网站显示的验证。
3. 返回软件重新搜索并打开漫画。

软件的网页登录机制会将网页 Cookie 保存给漫画源使用。外部浏览器完成验证，不保证软件也能通过。网页验证与网站账号登录是两回事；部分功能可能仍需登录网站账号。

## 图片线路

默认设置为 **自动切换（推荐）**：优先尝试 `as.baozimh.com`，失败后尝试 `as-rsa1-usla.baozicdn.com`，最后尝试网页返回的原始图片线路。

如图片持续加载失败，可在本源的设置中选择“线路一”“线路二”或“网页原始线路”。指定线路会优先尝试，仍会提供其他线路作为回退；“网页原始线路”只使用原始地址。

搜索、详情及首个章节入口固定使用 `https://www.baozimh.com`。漫画图片、封面及同章分页允许使用网站关联服务器；不保证所有网络请求只访问一个域名。

## 验证范围与已知限制

- JavaScript 语法和离线回归检查通过，运行方式：`node --check baozi.js`、`node --test tests/source.test.cjs`。
- 2026-10-06，在维护者测试环境中，同一章节的三张图片通过默认图片线路返回 HTTP 200，内容为 JPEG；备用线路的一张样本图片也返回 HTTP 200。
- 上述结果不等于 Android、Windows 的完整实机阅读验证，未保证所有漫画、章节、设备或网络均可用。
- 网站验证可能过期；图片线路也可能变化或暂时不可用。遇到验证提示时，重新使用网页登录。
- 脚本处理网页提供的图片和可识别的同章分页；网站结构变化、受限章节或动态加载可能需要后续适配。
- 封面服务器偶发错误与正文图片线路错误可能分别发生。

## 反馈问题

提交 Issue 时说明软件版本、Android/Windows 平台、漫画及章节名称、发生时间、图片线路和错误提示。日志应只保留本次问题相关片段，先删除账号、密码、Cookie、token 和个人信息。
